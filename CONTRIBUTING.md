# Contributing

AnglePlates is a small C# templating library. Changes should make templates easier to write or keep the generator straightforward to maintain.

Open an issue for a bug or a larger proposal. For a fix, include a template that reproduces the problem and a focused test. Keep unrelated cleanup out of the pull request, review changed snapshots, and update docs when behavior changes.

[Developing AnglePlates](docs/development.md) has the build, test, and package commands. [The template reference](docs/templates.md) describes the supported behavior.
